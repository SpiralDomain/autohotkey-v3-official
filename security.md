## 🎯 What is AutoHotkey v3?

**AutoHotkey (AHK)** is a free, open-source scripting language for Windows that lets you automate almost anything — from simple keyboard shortcuts to complex GUI applications. It's the Swiss Army knife of Windows automation.

**Version 3** represents a complete modernization of the language: a new object-oriented syntax, better performance, native Unicode support, and a cleaner, more consistent API.

### 🛠️ What Makes v3 Different?

| Aspect | v1 | v2 | **v3** |
|--------|:--:|:--:|:------:|
| 🔷 Syntax | Legacy | Modern | **Unified** |
| 💨 Speed | Baseline | 2× | **5×** |
| 🧩 Objects | Basic | Full | **Enhanced** |
| 🌐 Unicode | Limited | Native | **Full** |
| 🔌 API | Inconsistent | Better | **Unified** |
| 📚 Libraries | Manual | Packages | **Built-in** |
| 🖼️ GUI | Old-style | Modern | **Native** |
| 🔒 Security | Basic | Good | **Enhanced** |

## 🧬 Scripting Fundamentals

### 🧮 Variables

```ahk
name := "AutoHotkey"
version := 3
isAwesome := true
numbers := [1, 2, 3, 4, 5]
settings := { theme: "dark", lang: "en" }
```

### ⌨️ Hotkeys

```ahk
; Ctrl+Alt+T → Open Terminal
^!t::Run "wt.exe"

; Win+E → Explorer
#e::Run "explorer.exe"

; Ctrl+Shift+S → Screenshot
^+s::{
    Run "snippingtool.exe"
}
```

### ✍️ Hotstrings

```ahk
::btw::by the way
::omw::on my way
::@gmail::yourname@gmail.com

; Dynamic replacement
::today::{
    Send FormatTime(, "yyyy-MM-dd")
}
```

### 🧩 Functions

```ahk
Greet(name) {
    return "Hello, " name "!"
}

ShowGreeting() {
    MsgBox Greet("World")
}

ShowGreeting()
```

### 🔀 Control Flow

```ahk
; If statement
if (x > 10) {
    MsgBox "Greater than 10"
} else {
    MsgBox "10 or less"
}

; Loop
Loop 5 {
    Send "Line " A_Index "`n"
}

; For loop
for index, value in [1, 2, 3] {
    MsgBox "Item " index ": " value
}

; While loop
counter := 0
while (counter < 5) {
    counter++
}
```

### 🏛️ Objects & Classes

```ahk
class Person {
    __New(name, age) {
        this.name := name
        this.age := age
    }
    
    Greet() {
        return "Hi, I'm " this.name
    }
}

person := Person("Alice", 30)
MsgBox person.Greet()
```

## 🎨 GUI Creation

### 🪟 Simple Window

```ahk
MyGui := Gui("+Resize", "My Application")
MyGui.Add("Text", , "Enter your name:")
nameEdit := MyGui.Add("Edit", "w300")
MyGui.Add("Button", "Default", "OK").OnEvent("Click", Submit)

MyGui.Show()

Submit(*) {
    MsgBox "Hello, " nameEdit.Value
}
```

### 🎭 Advanced Layout

```ahk
App := Gui("+Resize +MinSize400x300", "AHK v3 Demo")
App.SetFont("s10", "Segoe UI")

; Header
App.Add("Text", "x10 y10 w380 h30 Center", "AutoHotkey v3 Demo")

; Input section
App.Add("Text", "x10 y50", "Command:")
cmdEdit := App.Add("Edit", "x80 y50 w310")

; Button row
App.Add("Button", "x10 y90 w100", "Execute").OnEvent("Click", RunCmd)
App.Add("Button", "x120 y90 w100", "Cancel").OnEvent("Click", (*) => App.Destroy())

App.Show()

RunCmd(*) {
    Run cmdEdit.Value
}
```

## 🚀 Common Automation Patterns

### 📝 Text Expansion

```ahk
::sig::
{
    SendInput "Best regards,`nJohn Doe`njohn@example.com"
}
```

### 🪟 Window Snapping

```ahk
#Left::{
    WinMove A_ScreenWidth * 0, 0, A_ScreenWidth / 2, A_ScreenHeight
}

#Right::{
    WinMove A_ScreenWidth / 2, 0, A_ScreenWidth / 2, A_ScreenHeight
}
```

### 📋 Clipboard Manager

```ahk
^+v::{
    ; Strip formatting on paste
    Send "^v"
}
```

### 🗂️ Batch File Renamer

```ahk
^!r::{
    folder := DirSelect()
    if (folder) {
        Loop Files, folder "\*.txt" {
            newName := StrReplace(A_LoopFileName, "old", "new")
            FileMove A_LoopFileFullPath, folder "\" newName
        }
    }
}
```

### 🚀 App Launcher

```ahk
!n::Run "notepad.exe"
!c::Run "calc.exe"
!e::Run "explorer.exe"
!b::Run "https://www.bing.com"
```

## 🩺 Troubleshooting

| Problem | Cause | Solution |
|---------|-------|----------|
| 🚫 Script won't run | Syntax error | Check line number |
| 🚫 Hotkey conflicts | Another app | Change binding |
| 🚫 Admin required | Elevation | Run as admin |
| 🚫 Script crashes | Bad code | Add try/catch |
| 🚫 Slow response | Heavy script | Optimize loops |
| 🚫 GUI invisible | Wrong coordinates | Use `Center` |
| 🚫 Compiler fails | Missing files | Reinstall |
| 🚫 VSCode no syntax | Extension | Install extension |
| 🚫 Path not found | Relative | Use absolute |
| 🚫 Unicode broken | Old file | Save as UTF-8 |

## 💬 FAQ

**Is AutoHotkey free?**
Yes — completely free and open source under GPL.

**Is v3 compatible with v1/v2 scripts?**
Not directly — a migration guide exists.

**Can I compile to EXE?**
Yes — the compiler is included.

**Does it work on Linux?**
Only via Wine with limited support.

**Can I sign my scripts?**
Yes — digital signing is supported.

**Does it work on ARM Windows?**
Yes — ARM64 native support.

**Is it safe to use?**
Yes — but only run scripts from trusted sources.

**Can I use it commercially?**
Yes — GPL allows commercial use.

**Does it support Unicode?**
Yes — native UTF-16 and UTF-8.

**Can I access the Windows API?**
Yes — via DllCall.
